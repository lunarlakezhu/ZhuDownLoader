# 快速上手

从零开始，到下载出第一篇 PDF。每一步都可以照抄。

## 第 1 步：装 Node.js（装过就跳过）

1. 打开 <https://nodejs.org/>，下载 **LTS** 版本。
2. 双击安装包，一路「下一步」装完。
3. 验证：按 `Win + R`，输入 `cmd` 回车，在黑窗口里输入 `node -v` 回车。显示出版本号（例如 `v22.x.x`）就是装好了。

> 判断技巧：也可以直接双击本项目的「一键安装环境.bat」，如果它提示缺 Node.js，就回来做这一步。

## 第 2 步：装浏览器内核（只需一次）

1. 在 ZhuDownLoader 文件夹里，双击 **`一键安装环境.bat`**。
2. 它会自动下载约 150MB 的 Chromium 浏览器内核（需要联网），跑完窗口会自己结束。
3. 以后换电脑之外的任何时候都不用再点它。

## 第 3 步：准备 DOI 清单

新建一个 `.txt` 文件（记事本就行），一行一个 DOI。格式很宽松，以下写法都能识别：

```
# 我的文献清单（# 开头的行是注释，会被跳过）
1. 10.1038/s41467-024-48293-2 某篇 Nature 论文标题
10.1109/LRA.2023.3322071
https://doi.org/10.1073/pnas.2314359121
```

- 从 Zotero / EndNote / 网页复制的列表直接整段粘贴即可，程序会自动提取 DOI、去重。
- 项目里自带的 `sample.txt` 就是一份可以拿来练手的清单。

## 第 4 步：开始下载（三选一）

### 方式 A：网页版（推荐新手）

1. 双击 **`网页版下载.bat`**，浏览器会自动打开 `http://127.0.0.1:7788`。
2. 把清单内容粘贴到页面文本框（或直接把 .txt 文件拖进页面）。
3. 选择保存位置，按需调整并发/重试（默认就行）。
4. 点 **「开始下载」**，进度表实时刷新。
5. 结束后可以一键打开 PDF 文件夹、复制或重跑失败清单。

详细说明见 [网页版使用指南](网页版使用指南.md)。

### 方式 B：拖拽

把清单 `.txt` 文件拖到 **`拖拽下载.bat`** 图标上，按提示输入输出目录即可。

### 方式 C：命令行

```powershell
# 在 ZhuDownLoader 文件夹打开 PowerShell（资源管理器地址栏输入 powershell 回车）
.\zhu-dl.ps1 -List 清单.txt -OutDir D:\Papers

# 不带参数则进入交互模式，逐项提问
.\zhu-dl.ps1
```

所有参数说明见 [清单格式与命令行参数](清单格式与命令行参数.md)。

## 第 5 步：看结果

| 位置 | 内容 |
|---|---|
| 输出目录下的 `*.pdf` | 下载好的文献（已通过 PDF 文件头校验） |
| 输出目录下的 `failed.txt` | 下载失败 + 需人工的 DOI 清单，**可直接作为下次的清单重跑** |
| 输出目录下的 `download.log` | 每篇一行日志：成功 / 无效 / 失败 / 需人工 / 已存在 + 原因 |

**失败重跑零成本**：把 `failed.txt` 再当清单跑一遍，已成功的会秒级跳过（识别为「已存在」）。

## 下载过程中会看到什么

- 下载 PNAS / Science / IEEE / Wiley / Company of Biologists / Royal Society / Oxford / ACS / APS / 美国生理学会 / SAGE / Elsevier / IOP Publishing 时会**自动弹出浏览器窗口**，这是程序在操作，别手动关（Nature / Springer / 剑桥哲学会 cambridge.org 不弹窗口，速度最快）。
- 下载 Elsevier 或 IOP Publishing 时若弹人机验证：勾选框程序会**先自动点一次**；弹图选等谜题或没自动放行时，到那个窗口里完成一次，其余全自动；同一批通常只处理一次。**ScienceDirect 在本机装有并运行 FlareSolverr 时不再弹窗口**，整篇全自动（约 40-60 秒/篇）；没装也不影响，自动走上面的近自动路径（见 [常见问题 FAQ](常见问题-FAQ.md)）。
- 屏幕上闪浏览器窗口、看板里条目状态跳动，都属正常现象。

遇到问题先看 [常见问题 FAQ](常见问题-FAQ.md)。
