# 网页版使用指南

网页版是最适合新手的入口：双击 `网页版下载.bat`，浏览器自动打开 `http://127.0.0.1:7788`，所有操作都在页面上完成。

## 启动与关闭

- **启动**：双击 `网页版下载.bat`。它会启动一个只监听本机（`127.0.0.1:7788`）的网页服务并自动打开浏览器——局域网里其他电脑访问不到，只在本机可用。
- **换端口**：端口被占用时，用命令启动：`node webui/server.mjs --port 7789`。
- **禁止自动开浏览器**：脚本/测试场景加 `--no-open` 参数。
- **中途关掉网页没关系**：下载在后台继续，重新打开 `http://127.0.0.1:7788` 能恢复进度现场。

## 页面操作流程

1. **粘贴清单**：把 DOI 清单粘贴到文本框，或直接把 `.txt` 文件拖进页面。
2. **预览确认**：页面会先解析出「待下载清单」（共 N 篇、跳过 M 个无法识别的行），确认无误再继续。
3. **选择保存位置**：默认目录之外可以自选；注意别选到系统重要目录。
4. **设置并发 / 重试**（可选）：默认并发 2、重试 1，一般不用动。
5. **点「开始下载」**：进度表实时刷新（服务端主动推送，不需要手动刷新页面）。
6. **结束后**：一键打开 PDF 文件夹；失败清单可一键复制回输入框重跑，或导出。

## 进度表状态怎么看

| 状态 | 含义 |
|---|---|
| ✓ 成功 | PDF 已下载并通过文件头校验 |
| ✓ 已存在 | 输出目录里已有这篇的 PDF，秒级跳过 |
| ✗ 失败 | 下载出错（会按设置自动重试）；看备注列的原因 |
| ⚠ 需人工 | 通常是 Elsevier / IOP Publishing 人机验证（图选谜题）等不到人完成；不会自动重试 |
| ⬇ 下载中 | 正在下载，备注列显示当前步骤 |
| · 待处理 | 排队中 |

Elsevier / IOP Publishing 文章备注出现「人机验证」类提示时，该行会以**琥珀色高亮**——勾选框程序会先自动点一次；若弹的是图选等人工谜题或自动点击未放行，此时切到弹出的 Edge 窗口手动完成一次即可（同一批通常只处理一次，之后文章共用验证会话）。

## 和命令行版的关系

网页版与命令行版**共用同一套下载核心与编排语义**（`lib/downloader.mjs` + `webui/batch.mjs`），行为完全一致：

- 已存在的 PDF 跳过；
- 失败按设置重试；
- 「需人工」不重试；
- 结束后在输出目录写 `failed.txt` 和 `download.log`。

所以两边随时可以换着用，结果不受影响。

## 网页版背后是什么（给好奇的人）

`网页版下载.bat` 实际执行 `node webui/server.mjs`：一个 Node 本机 HTTP 服务，页面通过 `/api/start` 提交批次、通过 `/api/events`（SSE 长连接）接收实时进度。技术细节见 [架构与文件地图](架构与文件地图.md)。
