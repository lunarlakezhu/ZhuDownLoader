# 清单格式与命令行参数

## DOI 清单格式（宽松解析）

一个 `.txt` 文件，每行任意位置含 DOI 即可识别：

```
# 我的文献清单（# 开头为注释，整行跳过）
1. 10.1038/s41467-024-48293-2 某篇 Nature 论文标题
10.1109/LRA.2023.3322071
https://doi.org/10.1073/pnas.2314359121
```

解析规则（CLI 与网页版共用同一套 `lib/listparse.mjs`）：

- **容忍脏数据**：「编号 + DOI」「DOI + 标题」「含 DOI 的 URL」混合行都能提取，兼容从 Zotero / EndNote / 网页复制的列表。
- **注释与空行**：`#` 开头跳过，空行跳过。
- **自动去重**：重复 DOI 只下一次（按小写比较）。
- **标点容错**：行尾悬挂的 `,` `.` `)` 等标点自动剥掉。
- **运行前确认**：会先打印「待下载清单」确认表（共 N 篇、跳过 M 个无法识别的行），再开始下载。

无法识别的行不会中断批次，只会在确认表里提示跳过了几个。

## 命令行参数

`zhu-dl.ps1`（PowerShell 入口）与 `batch_download.mjs`（直接 node）参数一一对应：

| zhu-dl.ps1 | batch_download.mjs | 默认 | 说明 |
|---|---|---|---|
| `-List` | 位置参数 1 | 交互询问 | DOI 清单文件路径 |
| `-OutDir` | 位置参数 2 | 交互询问 / `下载\ZhuDownLoader` | 输出目录 |
| `-Concurrency` | `-c, --concurrency` | 2 | 并发数。浏览器任务每篇弹一个窗口，建议 ≤4；ScienceDirect 建议 ≤2 |
| `-Retries` | `-r, --retries` | 1 | 单篇失败后自动重试次数（「需人工」不重试） |
| `-Plain` | `--plain` | 关 | 看板符号换 ASCII，旧版 conhost 显示乱码时用 |
| `-OpenManual` | `--open-manual` | 关 | 批次结束后统一为「需人工」条目打开 Edge |

示例：

```powershell
.\zhu-dl.ps1 -List 清单.txt -OutDir D:\Papers
.\zhu-dl.ps1 -List 清单.txt -OutDir D:\Papers -Concurrency 1 -Retries 2
.\zhu-dl.ps1                # 无参数进入交互模式，逐行提问

# 直接 node（适合脚本调用/CI）
node batch_download.mjs 清单.txt D:\Papers -c 2 -r 1
```

> 项目根目录的 `清单-订阅文全覆盖测试.txt` 是一份现成的验收级测试清单：以订阅文为主案例、
> 覆盖代码中全部 24 个出版商策略，含全 OA 对照、无权限负路径与特殊条目（2026-09-25 核验），
> 跑法与预期写在文件头注释里。

## 单篇下载

```powershell
node pw_download.mjs <DOI> [输出目录]
```

只下一篇文章时用这个，走的是同一套下载核心。

## 退出码

| 退出码 | 含义 |
|---|---|
| 0 | 全部完成（含「已存在」） |
| 1 | 有失败或需人工条目 |
| 2 | 参数错误 / 清单文件读取失败 |

脚本化调用时可以靠退出码判断批次是否干净。

## 产物文件

| 文件 | 说明 |
|---|---|
| `<输出目录>/<DOI合法字符>.pdf` | 下载产物，写入前已做 `%PDF-` 文件头校验 |
| `<输出目录>/failed.txt` | 失败 + 需人工的 DOI，每行一个，**可直接作为下次 `-List` 输入重跑**（已成功的会秒级跳过） |
| `<输出目录>/download.log` | 逐条追加的单行日志（成功/无效/失败/需人工/已存在 + 原因） |

## 看板（命令行版）

TTY 下整表 ANSI 重绘（约 250ms 节流，进行中条目耗时每秒跳动）；重定向到文件/管道时自动退化为逐行日志。清单超过 50 条时折叠成功条目，只显示进行中与有问题的条目。

```
文献下载看板  共 12 篇 | ✓ 成功 5  ✗ 失败 1  ⚠ 需人工 1  ✓ 已存在 2  ⬇ 下载中 3  · 待处理 2
  #  DOI                            出版商   状态       耗时    说明
  1  10.1038/s41467-024-48293-2     NATURE   ✓ 成功     6.4s   2263KB
  2  10.1073/pnas.2314359121        PNAS     ⬇ 下载中   12s    点击 Download PDF...
  4  10.1016/j.xxx                  ELSEVIER ⚠ 需人工          人机验证等待超时(2分钟未通过)
  5  10.1109/LRA.2023.3322071       IEEE     · 待处理
```

状态机：`待处理 → 解析中 → 下载中 → 校验中 → 成功 / 失败 / 需人工 / 已存在`。
