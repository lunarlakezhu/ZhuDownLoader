# 迁移到新电脑

把 ZhuDownLoader 搬到另一台 Windows 电脑，三步搞定。最短路径说明也在项目根目录的 `新电脑三步上手.txt`（记事本可直接看）。

## 要带走的文件

最省事：使用当前项目生成的 **`ZhuDownLoader-win-修复版.zip`**。它包含源码和 `node_modules`，不包含登录资料、测试 PDF 或下载目录；在另一台 Windows 电脑解压后按下文安装浏览器内核。之后若源码继续改动，运行 `build_win_zip.py` 重新打包。

> `ZhuDownLoader-win-修复版.zip` 已做归档内容检查，并在解压副本中通过语法、批次和网页服务测试。原有 `ZhuDownLoader-win.zip` 是 2026-09-05 的旧包，未包含 2026-09-25 的官网会话复用与人工验证后重试修复。

## 三步安装

### 第 1 步：装 Node.js（这台电脑没装过才需要）

1. 打开 <https://nodejs.org/>，下载 **LTS** 版，一路下一步装完。
2. 验证：`Win + R` → 输入 `cmd` 回车 → 输入 `node -v` 回车，显示版本号即成功。

### 第 2 步：双击 `一键安装环境.bat`

自动下载下载文献用的 Chromium 浏览器内核（约 150MB，需联网）。**只跑这一次**，以后不用再点。

### 第 3 步：双击 `网页版下载.bat`

浏览器自动打开下载页面：粘贴 DOI 清单 → 确认保存位置 → 点「开始下载」。

### 可选：装 FlareSolverr（让 ScienceDirect 全自动）

上面三步完成后，Elsevier（ScienceDirect）走近自动路径（通常一批点一次验证勾选框）。若想让 ScienceDirect **全自动无人工**：到 [FlareSolverr 官方发布页](https://github.com/FlareSolverr/FlareSolverr/releases/tag/v3.5.2) 下载 **Windows x64** 包解压到任意文件夹（程序体积大，单独安装），在解压目录的地址栏输 `powershell` 回车，执行 `$env:HOST='127.0.0.1'; .\flaresolverr.exe` 并保持窗口开着。下载文章期间开着它就行；没开也不影响其他任何下载。详见 [常见问题 FAQ](常见问题-FAQ.md)。

## 新电脑必读提醒

- 下载 PDF 需要在**校园网内**（靠学校的机构订阅）；OA 文不受限。
- 需要浏览器的出版商会打开下载器专用 Edge。若程序提示“需人工”，在该 Edge 中完成官网登录或验证，然后在网页版点“验证完成后重试”，或在单篇/批量命令的提示处按 Enter。
- 下载 Elsevier（ScienceDirect）或 IOP Publishing（iopscience.iop.org）时若弹人机验证：勾选框程序会先自动点一次；弹图选等谜题或没自动放行时，到窗口里完成一次，其余全自动（同一批通常只处理一次）。
- 更多说明见 [快速上手](快速上手.md) 和 [常见问题 FAQ](常见问题-FAQ.md)。
