# 常见问题 FAQ

## 下载相关

### FlareSolverr 是什么？装了有什么好处？

[FlareSolverr](https://github.com/FlareSolverr/FlareSolverr/releases) 是一个可选的本机小服务。装好并运行后（监听 `127.0.0.1:8191`），**ScienceDirect（Elsevier）文章会自动改为全自动下载**：不再弹验证窗口、不用人值守（约 40-60 秒/篇）；没权限的文章直接报「无PDF权限」。程序会自动探测服务在不在——没装或没开就自动走原来的 Edge 路径，一切照旧，不影响其他出版商。安装：官方发布页下载 Windows x64 包解压，在解压目录执行 `$env:HOST='127.0.0.1'; .\flaresolverr.exe`，保持窗口开着即可（程序体积大，单独安装，不随工具打包）。

### 提示「请验证您是真人」/ "I'm not a robot"，怎么办？

出现验证或机构登录时，要在**下载器专用 Edge** 中完成；日常 Edge 的登录状态不会自动共享。单篇命令会等待你完成后按 Enter 重试，批量命令可用 `--open-manual`，网页版在汇总页点「在下载器 Edge 中登录或验证」后再点「验证完成后重试」。会话 cookie 会导出并在下次启动补回缺失项。图选谜题、滑块、OTP 等由用户完成。

### 为什么下载时会弹出很多浏览器窗口？

部分出版商官网需要真实有头浏览器来通过机器人检测（具体哪些会弹窗口见 [快速上手](快速上手.md)）。并发 2 时屏幕上会先后闪出窗口，属正常现象，别手动关。觉得乱可以 `-Concurrency 1` 逐篇下。

### 下载失败怎么办？

1. 看备注列或 `download.log` 里的失败原因。
2. 若是“需人工”，先在下载器 Edge 中完成官网验证或机构登录，然后用同一会话重试。其他临时错误可把 `failed.txt` 重新当清单跑一遍（已成功的秒级跳过）。
3. 仍失败的看失败详情属于哪类：人机验证、页面无 PDF 链接、还是确定的权限提示，分别对照下面的条目处理。

### 提示「无PDF权限」（尤其 Wiley / Royal Society / Oxford / ACS / APS / 美国生理学会 / SAGE / IOP 订阅刊）

先看失败详情。出现人机验证页时并不能证明没有订阅——先完成验证再看；“需人工”表示验证未放行。确认是权限问题时，核查机构登录状态及该刊订阅范围。程序只把文件头为 `%PDF-` 的正文保存为成功，补充材料不代替正文。

### 芝加哥大学出版社（journals.uchicago.edu）的条目全部「连接超时」

该域名在境内直连网络被 **DNS 污染**（解析到假 IP），不开代理时浏览器和程序都连不上，属网络环境问题、不是工具故障。开代理/VPN（系统代理对浏览器生效）后把 `failed.txt` 重跑即可。

### 某个 DOI 一直卡在「下载中」

IEEE 下载可能较慢；长时间无进展可 Ctrl+C 中止后重跑（已成功的会跳过）。若官网明确提示无 PDF 访问权限，下载器会标“需人工”，请在下载器 Edge 中完成机构登录后重试。

### 已下载过一次，重跑会重复下载吗？

不会。输出目录里已有同名 PDF 的条目直接标「已存在」秒级跳过。

## 环境相关

### 中文 / 符号乱码

- `zhu-dl.ps1` 已内置 `chcp 65001` + UTF-8 输出，正常不乱码。
- 直接跑 node 且用旧版 conhost 窗口乱码时，加 `--plain` 参数把看板符号换成 ASCII。

### 双击 .bat 一闪而过 / 没反应

多半是没装 Node.js。先按 [快速上手](快速上手.md) 第 1 步装 Node.js，再双击 `一键安装环境.bat` 装浏览器内核。

### 换了台电脑怎么用？

见 [迁移到新电脑](迁移到新电脑.md)：装 Node.js → 双击 `一键安装环境.bat` → 双击 `网页版下载.bat`，三步完事。

## 网页版相关

### 网页打不开 / 端口被占用

用命令换端口启动：`node webui/server.mjs --port 7789`。

### 关掉网页下载会中断吗？

不会，下载在后台继续。重开 `http://127.0.0.1:7788` 能恢复进度现场。

### 网页只有我自己能打开吗？

是。服务只监听本机 `127.0.0.1`，局域网其他设备访问不到。

## 边界与合规

### 工具会绕过验证码 / 付费墙吗？

不会绕过付费墙，这是设计红线：

- 对验证控件只做**有界自动操作**：勾选框（Turnstile / hCaptcha "I'm not a robot"）自动点一次；图选谜题、滑块、验证码图片、press & hold 等**绝不自动操作**——出现时程序停下来等人完成，绝不尝试破解。
- 付费文章依赖你所在机构的合法订阅权限（校园网 IP），工具不破解任何权限、不绕过 DRM。

### Elsevier（ScienceDirect）为什么经常需要处理验证？

ScienceDirect 是各出版商里验证最频繁的站点之一。推荐本机装上 [FlareSolverr](https://github.com/FlareSolverr/FlareSolverr/releases)（见本文第一条），装好后即全自动；不装则近自动——一批通常只需处理一次验证，程序会先自动点一次勾选框，弹图选谜题才需要人完成。
